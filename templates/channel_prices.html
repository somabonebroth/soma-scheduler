Price-only repair. This re-reads a week from the channel and writes line_total / unit_price onto sale rows already on file. It never creates or removes a sale, and never touches quantity, lots, or finished-goods stock — the stock deduction happened at import time and does not run again.

Preview first. A row is left untouched if the channel can't confirm it — the SKU is gone from the re-read, or the channel's quantity no longer matches what was imported (a refund or order edit since). Those are reported, never guessed at.

Note Shopify only serves orders from roughly the last 60 days unless the app holds the read_all_orders scope, so older weeks may come back empty.
Use this for a week Soma has no sales for at all — a failed import leaves no rows, so it won't appear below.
